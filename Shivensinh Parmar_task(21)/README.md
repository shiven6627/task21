
- Omnifood Landing Page

Omnifood is a responsive food delivery landing page created using HTML and CSS. The project focuses on creating a clean food delivery website that works on desktop, tablet, and mobile screen sizes.

#Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Font Awesome
- Google Fonts

- - Website Sections

The website contains the following sections:

1. Navigation bar
2. Hero section
3. How It Works
4. Our Cities
5. Customer Reviews
6. Pricing Plans
7. Footer

- -Hero Section

The hero section introduces the Omnifood service with a food delivery themed background image.

It contains:

- Main heading
- "I'm Hungry" button
- "Show me more" button
- Navigation menu

The background image uses a dark overlay so that the white heading and buttons remain easy to read.

- - How It Works

This section explains how a customer can use the Omnifood service.

There are three steps:

1. Choose a suitable plan and sign up.
2. Pay for the plan and download the application.
3. Start ordering healthy meals.

A mobile phone mockup is also included. The phone screen uses "phone.jpg", which is intended to show an actual food delivery application interface.

The section also contains Google Play and App Store buttons.

- - Our Cities

The website displays four cities:

- Lisbon
- London
- Berlin
- San Francisco

Each city card contains:

- City image
- Number of happy eaters
- Number of chefs
- Twitter username

- - Customer Reviews

The testimonials section contains three customer reviews.

Each review includes:

- Customer comment
- Customer image
- Customer name

The section uses a dark food-related background image with an overlay so the white text remains readable.

- - Pricing Plans

The website contains three pricing plans:

- Premium
- Pro
- Starter

Each pricing card contains:

- Plan name
- Price
- Meal information
- Features
- Sign-up button

The Premium plan is highlighted using an orange top border.

- - Responsive Design

CSS media queries are used to change the layout for different screen sizes.

- - Desktop

On larger screens:

- Four city cards are displayed in one row.
- Three pricing cards are displayed in one row.
- Three customer reviews are displayed in one row.
- The How It Works section uses two columns.

- - Tablet - 850px

At 850px and below:

- City cards change from four columns to two columns.
- Pricing cards change from three columns to two columns.
- Reviews use two columns.
- The phone becomes slightly smaller.
- Navigation spacing and some font sizes are reduced.

- - Mobile - 600px

At 600px and below:

- City cards use one column.
- Pricing cards use one column.
- Reviews use one column.
- How It Works uses one column.
- Footer changes to a vertical layout.
- Navigation changes to a hamburger menu.
- Hero heading becomes smaller.

- - Mobile Navigation

The mobile menu is created using a checkbox and CSS.

JavaScript is not required for opening and closing the navigation menu.

When the checkbox is selected, the navigation links become visible.
