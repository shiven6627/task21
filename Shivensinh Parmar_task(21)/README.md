- Omnifood Landing Page

This project is a responsive food delivery landing page made using HTML and CSS.
#Technologies Used

- HTML
- CSS

#Sections in the Website

The website contains the following sections:

1. Hero section
2. Navigation bar
3. How It Works
4. Our Cities
5. Customer Reviews
6. Pricing Plans
7. Footer

#How It Works

This section explains the basic steps for using the food delivery service.

There are three steps:

1. Choose a suitable plan and sign up.
2. Pay for the plan and download the app.
3. Start ordering food.

There is also a phone design showing the food application and buttons for Google Play and App Store.

#Our Cities

The website shows four cities:

* Lisbon
* London
* Berlin
* San Francisco

Each city has an image and some information about customers, chefs, and Twitter.

#Customer Reviews

There are three customer reviews on the website.

Each review contains:

* Customer comment
* Customer image
* Customer name

#Pricing

There are three plans:

* Premium
* Pro
* Starter

Each plan shows the price, features, and a sign-up button.

- Responsive Design

I used CSS media queries to make the website work on different screen sizes.

- Desktop

For larger screens, the website uses multiple columns.

For example:

* 4 city cards are displayed in one row.
* 3 pricing cards are displayed in one row.
* 3 customer reviews are displayed in one row.
* The How It Works section has two columns.

- Tablet - 850px

When the screen width becomes 850px or smaller, I reduce the number of columns.

For example:

* Cities change from 4 columns to 2 columns.
* Pricing changes from 3 columns to 2 columns.
* Reviews change to 2 columns.
* Some spacing and font sizes are reduced.

I used this breakpoint because the desktop layout starts becoming too crowded on smaller screens.

- Mobile - 600px

When the screen width becomes 600px or smaller, most sections use one column.

For example:

* Cities use one column.
* Pricing cards use one column.
* Reviews use one column.
* How It Works changes to one column.
* Footer changes to a vertical layout.
* The navigation changes to a hamburger menu.
* Hero text becomes smaller.

This makes the website easier to use on mobile phones.

- Navigation

For the mobile navigation, I used a checkbox and CSS instead of JavaScript.

The menu icon appears on small screens. When the user clicks it, the navigation links are displayed.
